# Internet Store

Десктопное приложение для интернет-магазина. Написано на C++ Builder, данные хранятся в базе Microsoft Access. Есть каталог, корзина, оформление заказа, админ-панель и выгрузка заказов в Word и Excel.

## Основные возможности

**Покупатель**
- регистрация и вход (проверка длины логина и пароля, логины не повторяются)
- каталог с поиском по первым буквам названия, фильтром по цене и сортировкой по цене и категории
- карточка товара с описанием и фото
- корзина: можно менять количество прямо в таблице, сумма пересчитывается сама, корзину можно очистить
- оформление заказа: адрес, способ оплаты (наличные или карта), назначение курьера и примерное время доставки

**Администратор**
- добавление, редактирование и удаление товаров
- просмотр пользователей, смена паролей, удаление аккаунтов
- журнал заказов с фильтром по дате
- выгрузка заказов за выбранную дату в Word (отчёт для печати) и в Excel (таблица с заголовками и границами)
- светлая и тёмная тема

## Технологии

- C++ Builder, RAD Studio 11.3, VCL
- Microsoft Access (`BD_KURS.mdb`), подключение через ADO (Jet OLEDB 4.0)
- экспорт в Word и Excel через OLE-автоматизацию (`CreateOleObject`)

## Структура проекта

```text
BD_KURS.mdb          база данных
Images/              фото товаров и иконки
InternetShop/
  Project1.cbproj    файл проекта
  DbConfig.h         пути к базе и картинкам
  Unit1              главное окно: каталог, фильтры, админ-панель
  Unit2              вход
  Unit3              регистрация
  Unit4              корзина и оформление заказа
  Unit5              карточка товара
  Unit6              журнал заказов и экспорт в Word/Excel
```

## Как запустить

Нужны Windows 10/11 и RAD Studio с C++ Builder. Для экспорта отчётов ещё нужен установленный Microsoft Office.
Открыть `InternetShop/Project1.cbproj` в RAD Studio и запустить.
